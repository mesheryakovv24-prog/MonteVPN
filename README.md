# 🛡️ MonteVPN — Личный VPN-клиент и сервис

Собственный кроссплатформенный VPN-клиент под брендом **MonteVPN** с поддержкой протоколов **VLESS Reality**, обхода ТСПУ/DPI и автоматическим разделением трафика (обход белых списков и сервисов РФ).

---

## 🚀 ЧАСТЬ 1: Настройка вашего сервера (Ubuntu 22.04)

### 1. Подключение к серверу по SSH
Откройте PowerShell на компьютере:
```bash
ssh root@IP_ВАШЕГО_СЕРВЕРА
```
*(вставьте ваш пароль, при вводе символы скрыты — это нормально).*

### 2. Установка панели 3X-UI в одну команду
Выполните:
```bash
bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
```
- Подтвердите установку: `y`
- Укажите логин администратора: например, `admin`
- Укажите пароль: ваш надежный пароль
- Укажите порт: например, `2053`

### 3. Настройка VLESS Reality (защита от блокировок)
1. Откройте в браузере: `http://IP_СЕРВЕРА:2053` и авторизуйтесь.
2. Перейдите в **Inbounds** (Подключения) ➔ **Add Inbound** (Добавить подключение).
3. Укажите:
   - **Remark**: `MonteVPN`
   - **Protocol**: `vless`
   - **Port**: `443`
   - **Security**: `Reality`
   - Нажмите **Get New Cert** (Сгенерировать ключи).
   - **Dest**: `dl.google.com:443` (или `yahoo.com:443`)
   - **SNI**: `dl.google.com` (или `yahoo.com`)
4. Сохраните (**Create**).

### 4. Получение ссылки
- В списке подключений нажмите на строку и скопируйте ссылку (начинается с `vless://`).
- Либо перейдите в настройки подписки панели (**Subscription**) и скопируйте Subscription URL.

---

## 📱 ЧАСТЬ 2: Настройка приложения MonteVPN

Откройте файл `lib/config/app_config.dart` и вставьте полученную ссылку в строку:
```dart
static const String defaultSubscriptionUrl = 'vless://...ВАША_ССЫЛКА...';
```
*(Также ссылку можно вставить прямо внутри запущенного приложения через кнопку настроек в правом верхнем углу).*

## ⚡ ЧАСТЬ 3: Бесплатная сборка APK через GitHub Actions

Вам не нужно устанавливать 20 ГБ программ на компьютер. GitHub соберет APK в облаке:

1. Создайте бесплатный аккаунт на [GitHub.com](https://github.com/) (если еще нет).
2. Создайте новый репозиторий: `monte_vpn` (можно выбрать **Private** / приватный).
3. В папке проекта выполните в терминале:
   ```bash
   git init
   git add .
   git commit -m "Init MonteVPN"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/monte_vpn.git
   git push -u origin main
   ```
4. Откройте вкладку **Actions** в вашем репозитории на GitHub:
   - Вы увидите процесс автоматической сборки (займет 2–3 минуты).
5. По завершении перейдите в **Releases** (или раздел Artifacts) и скачайте готовый файл **`MonteVPN.apk`** прямо на ваш телефон!

## 🇷🇺 Как работает обход сайтов РФ:
- В приложении встроен тумблер **«Обход сайтов РФ»** (включен по умолчанию).
- Российские банковские приложения (Сбер, Т-Банк, ВТБ), Госуслуги, Ozon, Wildberries и сайты в зоне `.ru` открываются напрямую через мобильного оператора без потери скорости.
- YouTube, запрещенные сайты, соцсети и нейросети безопасно идут через зашифрованный туннель MonteVPN.
